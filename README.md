# Arclo Cleaning Website: Master Template

The reusable master website for cleaning-company clients, built with
**TanStack Start + React 19 + TypeScript + Tailwind CSS v4 + Vite** (Nitro server,
deploys to Vercel). The demonstration brand is **Sparkle Rush**.

> This repository is the **master**. Never put a real client's details in it.
> To build a client site, duplicate it and follow [CLIENT_SETUP.md](./CLIENT_SETUP.md).

## Run locally

Requires Node.js 20+ and npm.

```sh
npm install
npm run dev        # Vite prints the local URL (usually http://localhost:5173)
npm run typecheck  # TypeScript
npm run lint       # ESLint (0 errors expected; a few shadcn fast-refresh warnings are normal)
npm run build      # production build (writes .vercel/output for Vercel)
npm run preview    # serve the production build locally
```

## Where things live

| You want to change…                                              | Edit                                       |
| ---------------------------------------------------------------- | ------------------------------------------ |
| Business name, phone, email, address, hours, service area        | `src/lib/business.ts`                      |
| Logo, brand colors, favicon, hero/about/gallery photos           | `src/lib/business.ts` + `public/`          |
| Lead form (Formspree endpoint, success/error messages)           | `src/lib/business.ts` → `form`             |
| Domain, canonical URL, search-engine indexing                    | `src/lib/business.ts` → `seo`              |
| Which services are offered (add / remove / reorder / rewrite)    | `src/lib/services.ts`                      |
| Image files                                                      | `public/images/` (paths in `src/lib/images.ts`) |
| Homepage FAQ                                                     | `src/lib/faq.ts`                           |
| Privacy Policy / Terms text                                      | `src/routes/privacy.tsx`, `terms.tsx`      |

Everything business-specific is read from those files at build time, so server-rendered
HTML, `<title>`/meta tags, Open Graph tags, JSON-LD structured data, `robots.txt` and
`sitemap.xml` always agree with what visitors see.

## Architecture in brief

- `src/lib/business.ts`: central business configuration + derived helpers (`phoneHref`, `absoluteUrl`, …).
- `src/lib/services.ts`: service catalog. `services` (enabled only) feeds the homepage grid, header dropdown,
  footer, estimate-form dropdown, related-services chips, sitemap and `/services/<slug>` pages.
- `src/lib/seo.ts`: `pageHead()` builds title/description/canonical/OG/robots/JSON-LD for every route; also the brand-color override.
- `src/components/estimate-form.tsx`: the single estimate form (hero, contact page and every service page).
- `src/routes/`: file-based routes. `robots[.]txt.ts` and `sitemap[.]xml.ts` are generated server routes.
- `src/routeTree.gen.ts` is auto-generated by the dev server / build; don't edit it by hand.

## Demo-site safety

The master is **not indexable**: every page sends `noindex, nofollow` and `/robots.txt` disallows all crawling
until `seo.indexable` is set to `true` (with a `siteUrl`) in a client copy. The lead form runs in an explicitly
labelled **demo mode** (nothing is sent) until a Formspree endpoint is configured.

There is intentionally **no in-browser settings editor**. The old `/settings` page stored overrides in
`localStorage`, which can't affect server-rendered content or SEO and would never reach real visitors, so it was removed.
